# AI Malnutrition Monitoring in Children

This project is an Artificial Intelligence-based application to monitor child malnutrition using Random Forest Classifier.

## Features
- Classification of nutritional status
- MUAC, BMI, and Z-score calculation
- WHO Growth Standards based analysis

## Technology
- Python
- Flask
- Scikit-learn

## How to Run
1. Install dependencies
```bash
pip install -r requirements.txt
```

2. Run the application
```bash
python app.py
```

3. Open the application in broswer
```bash
http://localhost:5000
